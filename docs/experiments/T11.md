# T11 · A better familiarity distance, and a "where it differs" heatmap

Ticket: [../TICKETS.md](../TICKETS.md) T11. Source: MODEL_LITERATURE_REVIEW §7.1. A v2 candidate study: the frozen model and its `outside_baseline` / `unfamiliar` flags are not changed. Data: the 31 known images.

## Pre-registered (committed before any distance was computed)

**Problem.** Today's baseline distance (RMS z over the model's features, standardised by Batch_3 strip segments) flags 1 of the 14 Batch_1/Batch_2 images (PLAN_v4 §3.16).

**Protocol (the same for every method).**

- **Reference:** Batch_3, 7 strips.
- **Batch_3 held-out scores:** for each Batch_3 strip, fit the reference on the other 6 strips and score that strip's images (17 scores).
- **Batch_1/Batch_2 scores:** each image is scored against each of the 7 six-strip references; its score is the median of the 7. Each reference is then exactly as large as when a Batch_3 image is scored.
- **Threshold:** the maximum of the 17 Batch_3 held-out scores, as today.
- **Metrics:**
  - **AUC** of the Batch_1/Batch_2 scores against the Batch_3 held-out scores (primary; threshold-free);
  - the number of the 14 Batch_1/Batch_2 images above the threshold.

**Methods (fixed list).**

| # | Method | Space |
|---|---|---|
| 0 | Today's RMS z: per-feature mean and SD over the reference's strip-segment means | the 180 usable material features (the frozen first stage's space) |
| a | Mahalanobis with Ledoit–Wolf shrinkage, fitted on the reference images | 10 deep PCs, PCA fitted on the reference images (`Reducer`) |
| b | Relative Mahalanobis [L48]: (a) minus the Mahalanobis distance under one Gaussian (Ledoit–Wolf) fitted on all images outside the scored image's strip, in the same PC space | same as (a) |
| c | Tile nearest neighbour, PatchCore-style [L31]. Memory bank = InLens tile embeddings of the reference images (`qc.deep` tiles, CLS + mean patch token, L2-normalised). Image score = mean nearest-neighbour Euclidean distance of its 10% most distant tiles | DINOv2-small tiles, as in `qc.deep` |

**Deliverable.** Per-tile distance heatmaps from (c) for 3 Batch_1 images (both strip 2316 images and `ffwubibz`), against the full 7-strip Batch_3 bank, saved as `docs/experiments/T11_heatmaps.png`.

**Not run (stated now).** The foreign test set ([L36], Zenodo NMC811 FIB-SEM) is a single 2.8 GB 7z archive; it is deferred to a later run.

**Reading rules.**

- A method is a **better familiarity distance** if its AUC is at least 0.15 above method 0's **and** it flags at least 4 of 14.
- If several qualify, report all; the choice is not made here.
- T9 found the folder signal predictable from acquisition, so a distance that separates Batch_1/Batch_2 from Batch_3 may do so through acquisition as well. This is stated next to any result.

## Results (4 Oct 2026, after the pre-registration commit `1972d52`)

Command: `PYTHONPATH=. uv run python scripts/experiments/T11_familiarity.py`. Outputs: `out/experiments/T11/scores.csv`, `result.json` and `tiles.npz` (InLens tile embeddings). The heatmap is `docs/experiments/T11_heatmaps.png`.

| # | Method | AUC (Batch_1/Batch_2 vs Batch_3 held out) | Flags of 14 at the Batch_3 maximum | Flagged |
|---|---|---|---|---|
| 0 | RMS z, material features (today) | 0.32 | 2 | `4ih2ggld`, `5n1q8atc` (strip 2316) |
| a | Shrunk Mahalanobis, 10 deep PCs | 0.54 | 0 | – |
| b | Relative Mahalanobis | 0.69 | 0 | – |
| c | Tile nearest neighbour (top 10% of tiles) | 0.71 | 0 | – |

**Reading, as pre-registered:** no method is a better familiarity distance. The AUC rule passes for (b) and (c), 0.37–0.39 above method 0, but neither flags anyone.

**What it shows** (interpretation):

- **Batch_3 is not one tight cluster.** Today's AUC is *below* 0.5: a held-out Batch_3 strip sits further from the other Batch_3 strips than most Batch_1/Batch_2 images do. Strips 1612 and 2060 (dark-graphite InLens, the 2060 imaging outlier) and 1904 dominate the held-out maximum. Any threshold set at "the furthest Batch_3 strip" is therefore wide.
- The tile and relative distances do rank Batch_1/Batch_2 higher (AUC about 0.7), but the spread of Batch_3 itself swallows the difference at the threshold.
- Today's distance flags exactly the two strip 2316 images, the different silicon population (T13). As a detector for **that** kind of difference it works.
- **Heatmap** (left to right: `4ih2ggld`, `5n1q8atc`, `ffwubibz`; red = tiles furthest from any Batch_3 tile, scaled per image): differences are patchy, a few tiles per image, not a uniform shift. Per-image scaling shows *where*, not *how much*.
- The T9 caveat applies: the tile distance runs on InLens, which T1, T2 and T9 show is acquisition-sensitive.
- The foreign test set was not run (deferred, as pre-registered).
