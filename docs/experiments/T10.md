# T10 · Texture at the material scale

Ticket: [../TICKETS.md](../TICKETS.md) T10. Source: MODEL_LITERATURE_REVIEW §5.1(b), §8.4 item 5. Stacked on T9 (it uses T9's erasure check). The frozen model is not changed; `tex2_` is a v2 candidate only. Data: the 31 known images.

## Pre-registered (committed before any run)

**Why.** Today's `tex_` features run on a 2× **subsampled** image (every second pixel, no averaging) at 0.05 µm. Detector shot noise passes through in full; material texture starts at about 0.2–0.5 µm (review §8.1). T9 found the `tex_` Batch_3-vs-rest signal collapses (0.88 → 0.50) once measured imaging is erased.

**New family `tex2_`** (computed in the experiment script; `qc/features.py` is not changed):

- **Work image:** per channel, black-subtracted, valid rows, then **4×4 block mean** → 0.1 µm/px. Averaging 16 pixels cuts the noise SD by about 4.
- **Per channel:** uniform LBP (P = 8) at R = 2 px (0.2 µm) and R = 5 px (0.5 µm), 10 bins each. GLCM (32 levels, the same quantisation as `tex_`) at distances 2 and 5 px (0.2 and 0.5 µm), angles 0° and 90°, giving contrast, homogeneity, energy and correlation per distance.
- **BSE LBP at R = 2** inside graphite and inside Si (mask from `segment()`, block-reduced by majority = the mask subsampled at the block centre).
- About 120 columns.

**Runs** (LOSO, nested `C`; nulls: 200 segment shuffles, seed 0):

| # | What | Compared with |
|---|---|---|
| 1 | Batch_3 vs rest on `tex2`: LOSO, plus null | `tex`: 0.88, null p95 0.71–0.74 |
| 2 | Median and max \|Pearson r\| of the family's features with `img_bse_noise`, `img_bse_sharpness`, `img_etd_sharpness` and `img_inlens_sharpness`, over the 31 images | the same for `tex` |
| 3 | Run 1 with T9's erasure (same 22 covariates, k = 3, scope "all"), plus null | `tex` erased: 0.50, null p95 0.71 |
| 4 | Three-way staged `tex2 > deep`: LOSO plus null, plus erased LOSO and its null | frozen recipe: 0.66; erased 0.46, null p95 0.51 |
| 5 | Noise and blur flips: for each Batch_3 strip, fit the Batch_3-vs-rest model on the other strips; predict that strip's images as they are, with Gaussian noise σ = 5 (seed `crc32("<image_id>:noise5")`) and with Gaussian blur σ = 1 px. Count changed calls out of 17 | the same with `tex` |

**Reading rule.** `tex2_` is called **the better first stage for a v2 model** only if all three hold:

- run 1 is above its null p95;
- run 3 is above its erased null p95;
- run 5 changes ≤ 1 of 17 calls for both noise and blur.

Otherwise: "texture at the material scale does not give an acquisition-robust Batch_3 signal either". Run 2 is descriptive.
